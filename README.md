## Descripción
Implementación en Java de los algoritmos de ordenamiento **QuickSort** (esquema de partición de Lomuto) y **ShellSort** (reducción de intervalos por mitades), desarrollada como parte de la práctica de la Unidad 5.

---

## Estructura del proyecto

```text
Metodos_de_ordenamiento/
├── QuickSort.java
├── ShellSort.java
└── Main.java
```

---

## Clonar, compilar y ejecutar localmente

1. Clonar el repositorio: 
Abre tu terminal y ejecuta:
git clone https://github.com/mariemcris2212-hue/QuickSort-y-ShellSort.git 
cd Metodo_Ordeanamiento

2. Compilar:
Si estás ubicado dentro de la carpeta que contiene el directorio Metodos_de_ordenamiento, compila las clases en Java con:
javac Metodos_de_ordenamiento/*.java

3. Ejecutar:
Desde esa misma carpeta superior (donde se encuentra Metodos_de_ordenamiento), ejecuta la clase principal:
java Metodos_de_ordenamiento.Main

---

## Ejemplo de salida de consola

```
--- QuickSort ---
Arreglo original:
[6, 1, 5, 8, 3, 2, 7, 4]
Arreglo ordenado con QuickSort:
[1, 2, 3, 4, 5, 6, 7, 8]

--- ShellSort ---
Arreglo original:
[6, 1, 5, 8, 3, 2, 7, 4]
Arreglo ordenado con ShellSort:
[1, 2, 3, 4, 5, 6, 7, 8]
```
